# Contributing to CampusNow

Thank you for your interest in contributing to CampusNow! CampusNow is an ongoing student-focused mobile application project, and contributions, ideas, bug reports, and improvements are welcome.

## About CampusNow

CampusNow is being built to provide students with a centralized platform for useful campus-related tools, information, and services.

The project is currently in early development. The `v0.0.x` releases primarily focus on establishing the UI, navigation, and overall application architecture.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git
- Expo CLI / Expo tooling
- Expo Go on an Android or iOS device, or an Android/iOS emulator
